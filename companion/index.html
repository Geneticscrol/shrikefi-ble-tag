Best on Android Chrome (OnePlus). Allow Bluetooth + Location when prompted. While connected, the page records a pin every few seconds if the tag is still in range. Tap Mark last seen anytime you are next to the tag.

iOS / limitations
  • iPhone Safari: Web Bluetooth is usually unavailable. Use LightBlue / nRF Connect for find-me (RSSI + alert). This map is Android Chrome primary.
  • Pins are your phone’s GPS at the moment the tag is seen — the ShrikeFi has no GPS chip.
  • Not Apple Find My / Google Find My Device. Range = Bluetooth only (~10–30 m indoors).
  • Needs a secure context (HTTPS or http://localhost). See README for OnePlus + adb reverse.
